# Requirements traceability

Every requirement in Chapter 4 (Section 4.2), mapped to the code that implements
it, the tests that check it, and the evidence that demonstrates it. The
requirement text is quoted from the thesis. Requirements that are not fully met
say so, and name the gap.

**Status** is one of **Done**, **Partly** (some of it exists; the gap is named)
or **Not implemented**.

Paths are relative to the repository root. Python test counts are from the run
recorded in `docs/test-results.xml`: **520 tests, all passing** (2026-11-12, commit
`3dd58f0`, **with a database available**, so the 123 database-backed tests ran). Without a
database, as in CI, the same suite gives 397 passed and 123 skipped. The interface adds
**135 component tests** (vitest, all passing, 2026-11-12). The end-to-end suite defines
**24 tests per engine** (Chromium and WebKit), one of which is the NFR-01 browser timing. Its last
recorded run (`docs/evidence/e2e_browsers.txt`, 2026-11-12, commit `b44c924`, an isolated scratch stack)
**passed all 48** (24 per engine, 0 failed, 0 flaky); the run before it (2026-10-29) predates the landing page and
the contact feature, when the suite held 10 per engine. System tests T-01 to T-08 are in
`docs/test-record.md`.

| NFR-02 | An interpretable explanation for at least 85% of the top-K recommendations across the evaluation dataset | **Not met (development split; test-split figure pending)** | `evaluation/evaluator.py` counts coverage over each query's top-10, to the strict rule fixed in `docs/scoring-policy.md` §7 **before** the generator was written | `tests/test_evaluation.py: test_computing_coverage_changes_no_ranking_metric`, `test_coverage_is_counted_over_the_whole_top_k_not_only_what_would_be_displayed`, `tests/test_explanation.py` | `results/dev/20261026-232037_46116e0/metrics.md`: `full` reaches **79.2%** against a target of 85%. So the held-out variant is what takes the figure below 85%, but it is not the whole shortfall. A worker using a withheld alias reaches no occupation, so no skill is inferred and none is shared, so there is nothing checkable to say. ### What would close the gaps

1. **NFR-02.** FR-09 and NFR-03 are now closed: the `ExplanationGenerator` exists as a separable component, and coverage is measured.
